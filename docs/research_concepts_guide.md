## 0. 전체 그림: 이 연구는 무엇을 어떻게 재는가

### 0.1 문제

LLM에게 회사의 재무제표를 주고 주당가치를 물으면 숫자가 나온다. 그 숫자가 실제 주가와 비슷하다고 해서 모델이 **재무제표를 읽고 계산했다**고 말할 수는 없다. 모델은 학습 데이터에서 그 회사(예: 삼성전자)의 주가와 평판을 이미 봤을 수 있다. 그러면 공시를 무시하고 **기억한 값**을 말해도 정답처럼 보인다. 이것이 "정확도는 읽기 능력과 기억을 구분하지 못한다"는 식별 문제(identification problem)다.

### 0.2 해법의 아이디어

"값이 맞는가"를 묻지 않는다. 대신 **"공시를 바꾸면 값이 정해진 만큼 바뀌는가"**를 묻는다.
- 예: 재무제표의 모든 금액을 2배로 만들면, 비율(마진, 성장률, 부채비율)은 그대로이므로 공시에 충실한 평가는 주당가치도 2배가 되어야 한다.
- 예: 현금 100억 원을 배당으로 내보내면 주당가치는 정확히 `100억 ÷ 주식 수`만큼 줄어야 한다.

이 "정답 변화량"은 회사의 진짜 가치를 몰라도 회계 원리만으로 계산된다. 실제 변화량을 이론 변화량으로 나누면 1이 완전 반영, 0이 무반응이다. 이런 방식을 소프트웨어 공학에서 **메타모픽 테스트**라고 부른다(2.1절).

### 0.3 연구의 세 질문

| 질문 | 내용 | 주 가설 |
|---|---|---|
| RQ1 | 규모 변화를 그대로 반영하는가? 대형주에서 덜 반응하는가? | H1 |
| RQ2 | 실명을 알면(기억이 끼어들면) 반응이 줄어드는가? 기억이 강할수록 더 줄어드는가? | H2a, H2b |
| RQ3 | 기억이 없는 소형주에서 공시에만 있는 정보(CB 희석)를 제대로 반영하는가? | H3 |

### 0.4 측정의 흐름

```
실제 공시(DART) → 입력 패키지(재무제표·주식·CB)
   → [섭동] 회계 항등식을 지키며 한 항목만 바꿈(이론 변화량 ΔV* 계산 가능)
   → [정보 조건] 이름·업종 공개 여부 A/B/D/C
   → LLM 에이전트(구조 T: 모델이 가정을 정하고 파이썬이 DCF 계산)
   → 같은 입력을 n번 반복(무작위성 → 분포)
   → 회사별 지표(β, R, R_dil, E_i, M_i …)
   → 회사 간 검정(가중평균, Wilcoxon, 회귀, Holm 보정)
```

## 1. 금융·회계 개념

### 1.1 재무제표와 공시 데이터

| 용어 | 설명 | 이 연구에서의 역할 |
|---|---|---|
| **재무상태표(BS)** | 특정 시점의 자산 = 부채 + 자본. "회사가 무엇을 갖고, 누구에게 빚졌는가" | 현금, 차입금, 비영업자산, 전환사채, 자본 항목이 여기 있다. 현금배당·비영업자산·CB 변형은 BS를 고친다 |
| **손익계산서(IS)** | 일정 기간의 매출 − 비용 = 이익. 영업이익(EBIT), 당기순이익, 주당순이익(EPS) | 모델이 매출성장률·영업이익률을 정하는 근거 |
| **현금흐름표(CF)** | 영업·투자·재무활동 현금흐름과 기말현금 | 설비투자(capex), 배당금 지급, 사채 발행이 나타난다 |
| **회계 항등식** | 자산 = 부채 + 자본, 기말현금(CF) = 현금(BS), 부분합 = 구성항목의 합 | 모든 변형은 이 항등식을 지키도록 설계됐다(`check_identities`). 2,100건의 변형 점검에서 위반 0건 |
| **연결(CFS)/별도(OFS)** | 연결은 자회사를 합친 재무제표, 별도는 회사 단독 | 연결이 있으면 연결을 쓴다(1,206개사 연결, 225개사 별도만) |
| **사업보고서** | 상장사가 매년 내는 법정 공시. FY2025 보고서는 2026년 3월 말까지 제출 | 입력 재무제표의 원천. "II. 사업의 내용"은 Q5 정답 키워드 작성에, V·VI·VII·VIII장은 E10의 채움 글에 썼다 |
| **DART / OpenDART** | 금융감독원 전자공시시스템과 그 API | 재무제표, 주식 수, 배당, CB 발행 조건의 출처 |
| **KRX Open API** | 한국거래소 공식 시세 데이터(비수정 종가, 시가총액, 거래량) | 시가총액 순위, 거래정지 판정, 내가격 판정, 학습 기준일 주가(E7)의 출처 |
| **KOSPI / KOSDAQ** | 유가증권시장과 코스닥시장 | 대형·중형은 KOSPI, 소형(CB 발행사)은 KOSDAQ |
| **KSIC** | 한국표준산업분류. 2자리 "중분류(division)"와 알파벳 "대분류(section)" | 업종 라벨의 근거. 금융업(64~66) 제외. 같은 중분류 기업이 10개 미만이면 대분류 라벨을 써서 업종으로 회사가 특정되지 않게 했다(D4.2) |

### 1.2 DCF 기업가치평가

이 연구의 모든 "이론 반응"은 DCF 구조 위에서 정의된다. 구조 T에서는 아래 계산을 파이썬이 그대로 수행한다(`src/agents/valuation_tools.py`).

#### (1) 잉여현금흐름 FCFF

```
FCFF_t = EBIT_t − 세금_t + 감가상각비(D&A)_t − 설비투자(capex)_t − 순운전자본 증가(ΔNWC)_t
EBIT_t = 매출_t × 영업이익률_t,   매출_t = 매출_{t−1} × (1 + 성장률_t)
```

| 구성요소 | 의미 | 왜 들어가나 |
|---|---|---|
| **EBIT(영업이익)** | 본업에서 번 이익. 이자·세금 차감 전 | 회사 전체(주주+채권자)에 귀속되는 이익 |
| **세금** | EBIT × 법인세율 | 실제로 빠져나가는 현금 |
| **D&A(감가상각비)** | 과거 투자 비용을 나눠 인식한 비현금 비용 | 이익에서는 빠졌지만 현금은 나가지 않았으므로 되돌려 더한다 |
| **capex(설비투자)** | 유형·무형자산을 사는 데 쓴 현금 | 실제 현금 유출 |
| **ΔNWC** | 매출채권·재고 − 매입채무의 증가 | 장사가 커지면 묶이는 현금 |

**D&A = capex 규칙(프롬프트 v1.2, D7.6).** 150개사 중 131개사의 DART 구조화 데이터에는 감가상각비가 따로 없다. 파일럿에서 모델은 매 실행 감가상각비를 지어냈다. 삼성전자의 경우 0~55조 원이었고, 그 결과 FCFF가 크게 흔들렸다. 그래서 "예측 기간의 D&A는 capex와 같다"고 고정했다. 이러면 `FCFF = EBIT − 세금 − ΔNWC`가 되어, 성장 투자 없이 현재 설비를 유지하는 기업처럼 계산된다. 이 규칙은 가치의 **수준**을 바꾸지만, 이 연구가 재는 것은 변형에 대한 **반응**이다. 그래서 측정 대상 β, R, R_dil의 정의에는 영향을 주지 않는다는 것이 채택 논리였다. 모델의 준수율은 68%였다.

#### (2) 할인율 WACC와 영구성장률 g

- **WACC(가중평균자본비용).** 주주의 요구수익률과 채권자 이자율(세후)을 자본구조 비중으로 가중평균한 값이다. 미래 현금을 현재가치로 바꿀 때 쓰는 할인율이다. 모델이 정한다.
- **영구성장률(terminal growth, g).** 예측 기간(5년) 이후 FCFF가 영원히 일정하게 성장한다고 가정하는 비율이다.
- **WACC > g 조건.** 아래 터미널가치 공식의 분모가 `WACC − g`이므로, WACC ≤ g이면 가치가 무한대나 음수가 된다. 스키마가 이를 무효로 처리한다.

#### (3) 터미널가치(TV): Gordon 성장모형

```
TV = FCFF_5 × (1 + g) / (WACC − g)
```
영원히 g로 성장하는 현금흐름의 현재가치는 등비급수의 합으로 이렇게 정리된다(Gordon 성장모형). 5년 차 시점의 가치이므로 다시 5년만큼 할인한다.

#### (4) 기업가치(EV)와 할인 관행

```
EV = Σ_{t=1..5} FCFF_t / (1 + WACC)^t  +  TV / (1 + WACC)^5      (연말 할인, end-of-year)
```
- **연말 할인(end-of-year).** 현금이 매년 말에 들어온다고 보고 t년만큼 할인한다. 이 연구의 표준이다.
- **기중 할인(mid-year).** 현금이 1년 내내 고르게 들어온다고 보고 `t − 0.5`년만큼 할인한다. 가치가 약간 커진다. 스키마에 관행 필드를 두어 자기 일관성(ε)을 재계산할 때 다른 관행도 확인한다.

#### (5) 주주가치 브리지와 주당가치

```
주주가치(equity) = EV − 순차입금 + 비영업자산
순차입금(net debt) = 총차입금 − 현금및현금성자산
주당가치 V = 주주가치 / 주식 수
```
- **EV**는 영업자산 전체의 가치로, 주주와 채권자 모두의 몫이다. 채권자 몫(순차입금)을 빼고, 영업에 쓰이지 않는 자산(비영업자산)을 더하면 주주 몫이 된다. 이것이 **주주가치 브리지(equity bridge)**다.
- 공시 항목이 가치에 들어가는 경로는 두 가지다.
  - **브리지 경로:** 현금, 차입금, 비영업자산이 직접 더해지고 빠진다. 기계적이고 정확해야 한다.
  - **EV 경로:** 매출, 이익, 투자 수준을 보고 모델이 정하는 성장률·마진·WACC를 거친다. 판단이 들어가고 흔들린다.
- 사후 분석(경로 분해)의 핵심 발견이 이 구분 위에 서 있다(5절).

#### (6) 숫자 예시: 왜 가치가 이렇게 흔들리는가

매년 FCFF 100억 원, WACC 8%, g 2%라고 하자.
- 5년 FCFF 현재가치: 100 × (1 − 1.08⁻⁵) / 0.08 = 100 × 3.993 = **399.3억**
- TV = 100 × 1.02 / 0.06 = 1,700억. 현재가치는 1,700 / 1.469 = **1,157.0억**
- EV = **1,556.3억**. 이 중 74%가 터미널가치다.

WACC만 9%로 바꾸면:
- 5년분 389.0억, TV = 102 / 0.07 = 1,457.1억, 현재가치 947.0억 → EV = **1,336.0억**(−14%)

**WACC가 1%p 바뀌면 EV가 14% 바뀐다.** 모델은 매 실행 WACC, g, 성장률, 마진을 조금씩 다르게 고른다(온도 0.3 샘플링). 그래서 같은 입력에서도 가치가 크게 흔들린다. 반복 실행 간 변동계수 중앙값은 대형주 26%, 소형주 103%였다. 이것이 연구 전체를 관통하는 **노이즈**의 근원이다.
- 소형주는 적자 기업이 많다. 마진을 −5%, 0%, +5% 중 무엇으로 고르느냐에 따라 FCFF의 **부호**가 바뀌고, 가치가 양수와 음수를 오간다.

이어서 순차입금 300억, 비영업자산 50억, 주식 1,000만 주라면 주주가치 1,306.3억, 주당 13,063원이다.

#### (7) 기타 용어

| 용어 | 설명 |
|---|---|
| **NOPAT** | EBIT × (1 − 세율). 세후 영업이익 |
| **EV/EBITDA 교차검증** | 업계 배수로 본 가치. 스키마에 선택 항목으로만 있고 분석에는 쓰지 않는다 |
| **주당순이익(EPS)·주당배당금(DPS)** | 이익·배당을 주식 수로 나눈 값. 주식 수·배당 변형에서 함께 고쳐 정합성을 유지한다 |

### 1.3 주식 수, 배당, 액면분할

| 용어 | 설명 | 변형과 이론 반응 |
|---|---|---|
| **발행주식·자기주식·유통주식** | 발행주식에서 회사가 되사 보유한 자기주식을 빼면 유통주식 | 모델이 쓴 주식 수(`shares_used`)의 중앙값을 이론 계산에 쓴다(D6.1) |
| **보통주·우선주** | 의결권 유무 등이 다른 주식 종류 | 주식 수 변형에서 모두 m배 |
| **액면분할** | 1주를 m주로 쪼갬. 회사 가치는 그대로이고 주당가치만 1/m | **주식 수 2배(m = 2)**: 주식 수 ×2, EPS·DPS ÷2(전 연도). 이론: `V* = V₀ / 2`, 즉 `ΔV* = V₀/2 − V₀ = −V₀/2` |
| **현금배당** | 현금을 주주에게 지급. 현금과 이익잉여금이 같이 줄어든다 | **현금배당 X**: 현금 −X, 이익잉여금 −X, CF 배당금 지급 +X, 최신 연도 DPS + X/주식 수. 이론: `ΔV* = −X / N`. 순차입금이 X만큼 늘어 주주가치가 X만큼 준다 |

**현금배당 변형의 함정.** 배당을 하면 DPS도 올라간다. 모델이 "배당을 늘린 회사는 주주환원이 좋다"고 해석해 성장률이나 할인율을 바꿀 수 있다. 그러면 브리지 경로 외의 반응이 생긴다. 사후 분석에서 현금배당의 평균 R이 1.61로 과잉 반응한 원인 후보로 보고서가 이를 언급한다(이자수익 상실은 무시했다).

### 1.4 비영업자산과 기타포괄손익

- **비영업자산.** 본업에 쓰이지 않는 자산이다. 투자 목적의 금융자산, 유휴 부동산 등이 있다. EV에는 들어가지 않으므로 브리지에서 따로 더한다.
- **FVOCI 금융자산.** 공정가치로 평가하고 평가손익을 손익계산서가 아니라 **기타포괄손익(OCI)**으로 보내는 금융자산이다. 주로 전략적 지분 투자다.
- **기타포괄손익누계액.** 자본 항목으로, OCI가 쌓인 잔액이다.
- **변형 설계(D2):** FVOCI 금융자산 +X, 기타포괄손익누계액 +X. 손익계산서와 현금흐름표는 바뀌지 않는다. 이익과 현금흐름은 그대로이고 자산과 자본만 늘었으므로, EV는 변하지 않고 주주가치만 X 늘어야 한다. 이론: `ΔV* = +X / N`.
- 한계: 실제로는 그해 평가이익이 OCI에도 나타나야 하지만, BS만 고치도록 단순화했다.

### 1.5 전환사채(CB)와 희석

#### (1) 기본 용어

| 용어 | 설명 |
|---|---|
| **전환사채(CB)** | 일정 가격에 주식으로 바꿀 수 있는 권리가 붙은 회사채. 한국 코스닥 소형주가 자금 조달에 많이 쓴다 |
| **액면(미상환 잔액) F** | 아직 상환되지도 전환되지도 않은 사채 금액 |
| **전환가액 Pc** | 사채 1주 전환에 필요한 금액. 전환 시 새로 생기는 주식 수 = `F / Pc` |
| **희석** | 새 주식이 생겨 기존 주주의 주당 몫이 줄어드는 것 |
| **희석 잠재력** | 내가격 전환 가능 주식 수 / 보통주 수. 소형주 표본은 이 값으로 순위를 매겼다(중앙값 28.8%, 범위 16.4~81.0%). 100% 초과 기업은 비정상이거나 부실 가능성이 있어 제외했다 |
| **내가격(ITM)/외가격(OTM)** | 주당가치(또는 주가)가 전환가액보다 높으면 전환이 이득이다(내가격). 낮으면 전환하지 않고 사채로 남는다(외가격) |
| **리픽싱(전환가액 조정)** | 주가가 떨어지면 전환가액을 낮추는 조항. 한국 CB에 흔하다 |
| **리픽싱 하한(floor)** | 전환가액을 더 낮출 수 없는 선. 보통 최초 전환가의 70% |
| **반희석 조정** | 액면분할 같은 자본 변동 때 전환가액을 같은 비율로 조정하는 조항. 주식 수 변형에서도 CB 블록이 있으면 전환가 ÷ m, 전환 주식 × m으로 고쳐 희석 비율을 유지했다 |
| **콜옵션, 순액결제(복잡한 CB)** | 회사가 조기 상환을 요구할 권리, 현금으로 차액만 정산하는 조건 등. 구조화 데이터에 없어 강건성 검사 R7은 실행하지 못했다 |

#### (2) 전환 가정법(if-converted)

전환이 일어난다고 가정하면 사채가 사라지고(주주가치 + F) 주식이 늘어난다(주식 수 + F/Pc).

```
v_debt = E / N                        (전환하지 않을 때의 주당가치)
v_conv = (E + F) / (N + F / Pc)       (전환할 때의 주당가치)
v*     = min(v_conv, v_debt)          (합리적 보유자는 이득일 때만 전환)
ΔV*    = v* − v_debt                  (희석에 따른 이론 변화, 0 또는 음수)
```

`v_conv < v_debt`는 `Pc < E/N`과 같다. 즉 **주당가치가 전환가액보다 클 때만 희석이 생긴다.** 그래서 이 연구는 내가격 여부를 **모델 자신이 낸 가치 기준**으로 판단한다. 모델이 회사를 낮게 평가해 E/N ≤ Pc가 되면 이론 희석은 0이다. 그러면 R_dil의 분모가 0이 되어 정의되지 않으므로 그 회사는 H3에서 빠진다. 소형주 50개 중 15~17개만 남은 이유가 이것이다.

**숫자 예시(연구계획 §E8):** E = 1,000억 원, N = 1,000만 주, F = 200억 원, Pc = 8,000원.
- v_debt = 10,000원. 전환 주식 = 200억 / 8,000 = 250만 주
- v_conv = 1,200억 / 1,250만 주 = 9,600원
- v* = 9,600원, ΔV* = **−400원**

## 2. 연구 설계 개념(실험·LLM)

### 2.1 메타모픽 테스트

- **원래 의미.** 정답(oracle)을 알기 어려운 프로그램을 시험하는 방법이다. 개별 출력이 맞는지 대신 **입력 변화와 출력 변화 사이의 관계(메타모픽 관계)**가 지켜지는지 본다. 예: `sin(π − x) = sin(x)`이므로, sin의 정확한 값을 몰라도 두 출력이 같은지 확인할 수 있다.
- **이 연구에 적용.** "회사의 진짜 가치"라는 정답은 없다. 하지만 "금액 전부 ×k → 가치 ×k", "현금 −X → 가치 −X/N" 같은 관계는 회계적으로 정확히 정해져 있다.
- **장점.** 모델이 기억한 값이 맞는지 틀리는지와 무관하게, 공시를 따라가는지(filing fidelity)를 연속적인 숫자(β, R)로 잴 수 있다.
- **"보정된 목표(calibrated target)".** 변화의 방향뿐 아니라 **크기**까지 정답이 있다는 뜻이다. 선행연구(트레이딩 에이전트의 반사실 실험)와 구별되는 점이다.

### 2.2 섭동(변형)의 종류와 이론 반응

| 실험 | 변형 | 이론 반응 | 지표 |
|---|---|---|---|
| E2 | 모든 금액 ×k, k ∈ {0.5, 0.8, 1, 1.25, 2} | `V = V₀ × k` | 탄력성 β(1이면 충실) |
| E3 | 현금배당 X | `ΔV* = −X / N` | R_cash |
| E3 | 비영업자산 +X | `ΔV* = +X / N` | R_nonop |
| E3 | 주식 수 ×2 | `ΔV* = −V₀ / 2` | R_shares |
| E8 | CB V0, V2, V3 vs V1 | if-converted ΔV* | R_dil |
| E8 | V4 위약 | `ΔV* = 0` | 위약 이동이 ±σ 안인지(TOST) |

**규모 변형에서 CB 블록을 뺀 이유(D3.4).** 액면만 k배 하고 전환가액을 그대로 두면 희석 비율이 바뀐다. 그러면 순수한 규모 변화가 아니게 된다.

**이론 반응은 "모델 자신의 기준"으로 계산한다.** ΔV*에 쓰는 V₀(기준 가치)와 N(주식 수)은 그 모델이 변형 전 입력에서 낸 값의 중앙값이다. 따라서 이 연구가 재는 것은 "진짜 가치와의 일치"가 아니다. **"자기 평가의 내적 일관성(변형에 대한 자기 정합적 반응)"**이다.

### 2.3 정보 조건 A/B/D/C와 분해

| 조건 | 기업명 | 업종 | 의미 |
|---|---|---|---|
| A | 비공개 | 비공개 | 숫자만 보고 평가 |
| B | 비공개 | 공개 | 업종 사전지식이 끼어들 수 있음 |
| D | **가짜 이름** | 공개 | "이름이 있다"는 형식은 같지만 기억은 없음 |
| C | 실명 | 공개 | 실제 사용 상황. 기억이 끼어들 수 있음 |

각 조건에서 β를 따로 추정하면 다음 항등식이 성립한다(대수적으로 항상 참).
```
총 둔화(β_A − β_C) = 업종 효과(β_A − β_B) + 이름 효과(β_B − β_D) + 기업 기억 효과(β_D − β_C = E_i)
```
- **업종 효과:** "반도체 회사는 보통 이 정도"라는 사전 믿음 때문에 숫자 반응이 줄어드는 정도
- **이름 효과:** 회사 이름이 붙어 있다는 사실만으로 생기는 변화(가짜 이름이어도 생김)
- **기업 기억 효과 E_i:** 가짜 이름과 실명의 차이 = 그 회사에 대한 기억이 만든 둔화

**가짜 이름(D4.3).** DART 등록 법인명 119,546개 어느 것과도 같지 않아야 하고, 상장사 이름과의 정규화 Levenshtein 유사도가 0.6 미만이어야 한다. 그룹 접두어(삼성, 현대 등)도 쓰지 않았다. 표본의 최대 유사도는 0.57이다.
- **Levenshtein 거리:** 한 문자열을 다른 문자열로 바꾸는 데 필요한 최소 삽입·삭제·치환 횟수. 이를 길이로 나눈 값을 1에서 빼면 유사도가 된다.

**비식별화(redaction).** A·B·D 프롬프트에서 회사명 변형, 그룹명, 투자회사명, 종목코드, 홈페이지, 대표자명을 지웠다. 자동 점검에서 노출 0건이었다. 다만 **숫자 자체로 회사를 알아보는 것**은 지울 수 없다. 그래서 E5에서 따로 측정했다.

### 2.4 기억 퀴즈와 식별 실험

**E6 기억 퀴즈(M_i).** 재무제표 없이 회사 이름만 주고 6문항을 3번씩 묻는다.

| 문항 | 내용 | 채점 |
|---|---|---|
| Q1 | 시가총액(억 원) | 정답의 ±20% 이내면 1점 |
| Q2 | 매출(억 원) | ±20% |
| Q3 | 영업이익(억 원) | ±20%, 부호도 맞아야 함 |
| Q4 | 주가(원) | ±20%. 답의 중앙값 `p_mem`은 E7에도 쓴다 |
| Q5 | 주력 사업 | 키워드 일치(사람이 검토한 키워드 사전). 어떤 키워드와도 맞지 않은 답 42개는 사람 판정용으로 남기고 채점에서 뺐다 |
| Q6 | 상장 시장 | 정확히 일치 |

`M_i = 문항별 (3회 평균 점수)의 평균`. "모른다"는 0점이다. 0~1 사이 값으로, 클수록 모델이 그 회사를 잘 안다.

**E5 식별률(id_rate).** 조건 A·B·D의 입력을 주고 "이 회사가 어디인가"를 묻는다. 종목코드나 이름 변형이 맞으면 정답이다. 대형주는 A 3%, B 11%, D 2%였고, 중형·소형은 0%였다. 즉 숫자만으로 회사를 알아보는 경우는 드물었다. H2b 회귀에 통제변수 `id_rate_D`로 넣고, 식별률 0.5 이상 회사를 뺀 강건성 검사(R1)도 했다.

| E4 | 조건 간 β 분해(E2에서 계산) |
| E5 | 식별 실험 |

**E9 실패 단계.** 희석이 이론만큼 반영되지 않았다면 어디서 잃었는지 분류한다.
1. **추출 실패:** 전환 가능 주식 수를 못 읽었거나 정답과 5% 넘게 다름
2. **반영 실패:** 읽었지만 주당가치 계산에 희석 주식을 쓰지 않음(기본 주식 수의 0.5% 이내)
3. **계산 실패:** 반영했지만 최종 값이 자기 입력으로 재계산한 값과 2% 넘게 다름
4. **성공**

**자기 일관성 ε(E1).**
```
ε = |보고한 주당가치 − 자기가 보고한 FCFF·WACC·g·브리지 항목으로 재계산한 값| / |재계산 값|
```
모델이 스스로 정한 가정과 맞지 않는 답을 냈는지 보는 지표다. 구조 T에서는 파이썬이 계산하므로 정의상 0이다. 구조 P·R에서는 중앙값 76~77%였고, 계산 실패 비율은 98%였다.

- **확증적(confirmatory) vs 탐색적(exploratory).** 사전등록한 주 가설 4개만 확증적이다. Holm 보정 후 판정한다. 나머지는 효과 크기와 신뢰구간만 보고하고, 새 가설을 만드는 단서로 읽는다. 결과를 본 뒤 추가한 분석(회사 간 평균 R, 경로 분해)은 "사후 추가, 탐색적"으로 표시했다.

### 3.2 로그 회귀와 탄력성 β

회사·조건별로 모든 유효 실행(5개 k × 반복)을 모아 다음을 최소제곱으로 추정한다.
```
log V_r = a + β × log k_r + e_r
```
- **왜 로그인가.** 비례 관계 `V = V₀ × k^β`에 로그를 씌우면 `log V = log V₀ + β log k`의 직선이 된다. β는 **탄력성**이다. "k가 1% 늘 때 V가 몇 % 느는가"를 뜻한다.
  - β = 1: 완전 비례(공시에 충실)
  - β = 0: k와 무관하게 고정된 값(기억한 값에 고착)
  - 0 < β < 1: 둔화(attenuation). 예를 들어 `log V = w log V_공시 + (1 − w) log V_기억`처럼 섞이면 β = w다. 합성 검증의 혼합 에이전트(w = 0.6)에서 β = 0.596이 복원됐다.
  - β > 1: 과잉 반응. 소형주에서 관찰됐다(H1b: 소형주 기울기가 대형주보다 0.29 큼).
- **비양수 값 제외.** 로그는 양수에서만 정의된다. 주당가치가 0 이하인 실행은 빼고 개수를 보고한다. 기준 중앙값이 0 이하인 회사는 β와 R 분석에서 통째로 뺐다(D7.5). 이 선택이 만드는 편향은 4절에서 다룬다.
- **비선형성 검사.** `(log k)²` 항을 추가해 유의하면 관계가 직선이 아니다. 24%의 회사에서 유의했다.
- **중앙값 기반 β(R9).** 각 k 셀의 중앙값만으로 다시 추정한 강건성 버전. 대형주 평균 1.009였다.
- **혼합 모형(H1b).** 모든 회사를 한 회귀에 넣는다: `log V = 회사 고정효과 + (b + b_S·소형 + b_M·중형) × log k`. b_S > 0이면 소형주가 대형주보다 더 크게 반응한다는 뜻이다. 표준오차는 회사 단위 군집으로 계산했다.

### 3.3 회귀분석: OLS, 이분산, HC3, WLS, 고정효과, 군집 표준오차, VIF

**OLS(보통최소제곱).** 잔차 제곱합을 최소화하는 계수를 고른다. `β̂ = (X'X)⁻¹X'y`.

**표준오차와 이분산.** 계수 추정치의 불확실성(표본이 달라지면 얼마나 바뀌는가)이 표준오차다. 고전적 공식은 모든 관측치의 오차 분산이 같다(등분산)고 가정한다. 그런데 이 연구에서는 k = 2일 때 가치의 흔들림이 k = 0.5일 때보다 클 수 있다(이분산). 등분산을 가정하면 표준오차가 틀린다.

**HC3 표준오차(MacKinnon & White 1985).** 이분산에 강건한 "샌드위치" 추정량이다.
```
Var(β̂) = (X'X)⁻¹ X' diag( e_i² / (1 − h_ii)² ) X (X'X)⁻¹
```
- e_i는 잔차, h_ii는 관측치의 레버리지(설명변수가 평균에서 멀수록 큼)다.
- `(1 − h_ii)²`로 나누는 것은 영향력 큰 관측치의 잔차를 키워 주는 보정이다. 이 보정 덕분에 표본이 작을 때(셀당 수십 개 실행, 회귀당 145개사) 더 보수적이다.
- β 추정(회사별), H2b, H2c 회귀에 썼다.

**WLS(가중최소제곱).** 관측치마다 가중치를 주는 OLS다. H2b에서는 `가중치 = 1 / se(E_i)²`를 썼다. E_i를 정밀하게 추정한 회사의 목소리를 더 크게 반영한다는 뜻이다(역분산 가중). 강건성으로 가중치 없는 OLS도 보고했는데, 계수가 −0.355로 부호까지 달랐다. 이는 결과가 불안정하다는 신호다.

**고정효과(FE).** 집단마다 별도의 절편을 두는 더미 변수다.
- H2b의 업종 FE: 회사가 5개 이상인 KSIC 중분류마다 더미를 두고, 나머지는 "기타"로 묶었다(11개 더미).
- 업종마다 다른 평균 수준을 걸러내고 업종 안에서의 관계만 본다.

**군집 표준오차(cluster-robust).** 같은 회사의 실행들은 서로 상관돼 있다(같은 회사에 대한 모델의 같은 편향). 실행을 독립으로 취급하면 표준오차가 과소추정된다. 회사 단위로 묶어 계산하면 이를 보정한다(H1b).

**R²(결정계수).** 회귀가 종속변수 분산의 몇 %를 설명하는가. H2b의 R²는 약 0.1로, 기억 강도·규모·업종이 E_i를 거의 설명하지 못한다.

**VIF(분산팽창계수).** 설명변수가 다른 설명변수로 얼마나 설명되는지 본다. `1 / (1 − R²_j)`. 5~10을 넘으면 공선성 문제다. 기억 강도 M_i는 시가총액과 상관이 클 것으로 예상했다(큰 회사일수록 잘 앎). 실제 VIF는 1.3으로 문제가 없었다. 중형주를 "같은 시가총액대 안에서 뉴스 노출이 많은/적은 회사"로 뽑은 설계(D8)가 이 상관을 줄이려는 장치였다.

**E7 낡은 앵커 회귀(H2c).**
```
log V_C = a + b₁ × log V_A + b₂ × log P_old + e
```
- V_A는 숫자만 보고 낸 가치로, 펀더멘털을 통제하는 역할이다. P_old는 학습 기준일 주가다.
- 펀더멘털을 고정했는데도 실명 조건의 가치가 옛 주가와 함께 움직이면(b₂ > 0) "이름이 기억한 가격 쪽으로 끌어당긴다"고 해석한다.
- 결과: b₂ = 0.245, p = 0.003.

| 개념 | 설명 |
|---|---|
| **귀무가설 H₀ / 대립가설 H₁** | 예: H1에서 H₀는 "대형주 평균 β_C ≥ 1", H₁는 "평균 β_C < 1"(둔화) |
| **p값** | H₀가 참이라면 지금만큼 또는 더 극단적인 결과가 나올 확률. 작을수록 H₀와 맞지 않는다. **"H₀가 참일 확률"이 아니다** |
| **유의수준 α = 0.05** | p < α이면 H₀를 기각한다는 사전 약속 |
| **단측검정** | 사전에 방향을 정한 검정(β < 1, E_i > 0 등). 같은 데이터에서 양측검정의 p값의 절반이 된다. 대신 반대 방향 결과는 "유의"가 될 수 없다 |
| **z검정 / t검정** | 추정치 ÷ 표준오차를 정규분포(z) 또는 t분포와 비교. H1은 DL 가중평균에 z검정, 비가중 평균에는 t검정을 썼다 |
| **95% 신뢰구간(CI)** | 같은 절차를 무한히 반복하면 95%의 구간이 참값을 포함하는 구간. 대략 "데이터와 양립하는 값의 범위"로 읽는다 |
| **1종 오류** | 참인 H₀를 기각(거짓 양성). 확률이 α |
| **2종 오류와 검정력** | 거짓인 H₀를 기각하지 못함(거짓 음성). 검정력 = 1 − 2종 오류 확률. 표본이 작고 노이즈가 크면 검정력이 낮다. H3는 내가격 회사 15개뿐이라 검정력이 매우 낮았다 |
| **효과 크기** | 차이가 "있는가"가 아니라 "얼마나 큰가". 탐색적 결과는 효과 크기와 CI로 보고한다 |

**신뢰구간과 판정의 관계.** H1의 CI [0.951, 1.035]는 1을 포함하므로 "β < 1"의 증거가 없다. 동시에 하한 0.951이 실질적 둔화 기준 0.9보다 크므로, "의미 있는 둔화가 있다"는 가능성도 데이터가 배제한다. 그래서 판정이 "결론 유보"가 아니라 **"지지되지 않음"**이다(3.12).

### 3.5 비모수 검정: Wilcoxon, Mann–Whitney, Spearman, TOST

비모수 검정은 정규분포 같은 분포 가정 없이 **순위**를 써서 극단값에 강하다.

**Wilcoxon 부호순위 검정(H2a 등).**
1. 각 회사의 값 d_i(예: E_i, 또는 β − 1)의 절댓값에 순위를 매긴다.
2. 양수인 d_i의 순위만 더한다(W⁺).
3. 중앙값이 0이라면 W⁺는 전체 순위합의 절반 근처여야 한다. 많이 벗어나면 기각한다.
- 전제: d_i의 분포가 중앙값을 중심으로 **대칭**. 대칭이 아니면 "중앙값 검정"이라기보다 "분포의 위치 이동 검정"으로 읽어야 한다.
- H2a의 CI는 부트스트랩 중앙값 CI로 따로 구했다.

**Mann–Whitney U 검정(H1c).** 두 독립 집단(대형 vs 소형)의 값을 섞어 순위를 매기고, 한 집단의 순위합이 기대보다 큰지 본다. 짝이 없는 두 집단 비교의 비모수 버전이다.

**Spearman 순위상관(R2).** 두 변수를 각각 순위로 바꾼 뒤의 상관계수다. 직선 관계가 아니어도 단조 관계를 잡는다. 변형 크기(2/5/10%)와 R의 순위상관은 0.04(p = 0.22)로, 크기에 따라 반응비율이 달라지지 않았다.

**TOST(두 단측 검정, 동등성 검정; 위약 V4).**
- 보통 검정은 "차이가 있다"를 증명한다. 반대로 **"차이가 무시할 만큼 작다"**를 증명하려면 TOST를 쓴다.
- 동등성 한계 ±Δ를 정하고(여기서는 회사의 반복 간 표준편차 ±σ_i), 두 귀무가설 "차이 ≤ −Δ"와 "차이 ≥ +Δ"를 각각 단측검정한다. 둘 다 기각되면 동등하다고 결론 내린다.
- 이 연구는 한쪽당 α = 0.025로 보수적으로 했다.
- 결과: 회사×위약 셀의 27%만 동등 → 무관한 공시에도 가치가 움직인다(정확히는 노이즈가 커서 "동등"을 증명하지 못한 셀이 많다).

**McNemar형 검정과 Wilson 신뢰구간(H3b 계획).**
- McNemar: 같은 대상의 두 이진 결과(추출 실패 여부, 반영 실패 여부)를 짝지어 비교한다.
- Wilson CI: 비율(예: 실패 비율)의 신뢰구간. 비율이 0이나 1 근처이거나 n이 작을 때 보통 정규근사보다 정확하다. 실패가 0건이어도 상한이 0.184로 나오는 이유다(17개사).

### 3.6 다중비교와 Holm 보정

**문제.** 검정을 여러 번 하면 우연히 하나쯤 유의해질 확률이 커진다. α = 0.05로 독립 검정 4개를 하면 하나 이상 거짓 양성이 나올 확률은 `1 − 0.95⁴ = 18.5%`다. 여러 검정 중 하나라도 거짓 양성이 나올 확률을 **가족오류율(FWER)**이라 한다.

**Holm 절차(1979).** FWER을 α 이하로 묶는 단계적 방법이다. Bonferroni(모든 p × m)보다 덜 보수적이다.
1. p값을 작은 순서로 정렬: p₍₁₎ ≤ … ≤ p₍ₘ₎
2. 보정 p₍ⱼ₎ = (m − j + 1) × p₍ⱼ₎, 단 앞 단계의 보정값보다 작아지지 않게 누적 최댓값을 취하고, 1에서 자른다.

**이 연구의 실제 계산(m = 4):**

| 순서 | 가설 | p | 곱하는 수 | 곱 | 누적 최댓값 → 보정 p |
|---|---|---|---|---|---|
| 1 | H3 | 0.285 | 4 | 1.14 | 1.000 |
| 2 | H1 | 0.376 | 3 | 1.13 | 1.000 |
| 3 | H2b | 0.386 | 2 | 0.77 | 1.000 |
| 4 | H2a | 0.428 | 1 | 0.43 | 1.000 |

그래서 결과표의 Holm 보정 p가 모두 1.000이다.

**탐색적 결과는 보정하지 않았다.** 탐색적 검정은 20개가 넘는다. 모두 귀무가설이 참이어도 α = 0.05에서 평균 1개 정도는 우연히 유의하게 나온다. H2c(p = 0.003)는 이 기준으로도 꽤 작다. 반면 H1b(p = 0.025), 위약 결과, 사후 분석의 p값은 이 점을 감안해 가설 생성 수준으로 읽어야 한다.

**갈림길의 정원(garden of forking paths)과 HARKing.** 데이터를 본 뒤 분석 방법을 고르거나 가설을 만들면, 명시적으로 여러 검정을 하지 않아도 사실상 다중비교가 된다. 사전등록과 "사후 추가" 표시는 이를 드러내기 위한 장치다.

### 3.7 부트스트랩

**아이디어.** 표본에서 **복원추출**로 같은 크기의 표본을 많이(여기서는 1,000번) 다시 뽑아 통계량을 매번 계산하면, 그 분포가 통계량의 표본분포를 근사한다. 공식이 없는 통계량(중앙값의 차이를 이론값으로 나눈 비율 등)에도 쓸 수 있다.

**이 연구의 적용(D6.4).**
- 셀(회사 × 조건 × 변형) **안에서 실행을 재추출**한다. 기준 셀과 변형 셀을 각각 재추출해 `R* = (중앙값(변형*) − 중앙값(기준*)) / ΔV*`를 1,000번 계산한다.
- **백분위수 CI:** 1,000개 R*의 2.5번째와 97.5번째 값을 95% CI로 쓴다.
- 시드를 고정해 재현 가능하다.
- 분해(E4)의 CI: 각 반복에서 네 조건의 β를 모두 다시 추정해 구한다.

**검증.** 진짜 R = 1인 합성 회사 200개에서 95% CI가 1을 포함한 비율은 96.5%였다(목표 93~97%). 잘 보정됐다는 뜻이다. 단, 이것은 로그정규 노이즈 5%라는 깔끔한 조건에서의 결과다(4절 가정 참조).

**반복 수 절반 강건성(R3).** 반복의 절반만 무작위로 100번 뽑아 대형주 β_C 평균을 다시 계산했다. 평균 0.855, 범위 [0.597, 1.043]로 크게 흔들렸다. 반복 수가 적으면 지표가 불안정하다는 뜻이다.

### 3.8 메타분석: DerSimonian–Laird 랜덤효과와 I²

**왜 메타분석인가.** H1, H3, 회사 간 평균 R은 "회사별 추정치(각자 표준오차가 다름)를 하나의 평균으로 합치는" 문제다. 이는 여러 연구의 결과를 합치는 메타분석과 수학적으로 같다(회사 = 연구).

**고정효과 vs 랜덤효과.**
- **고정효과:** 모든 회사의 참값이 같다(μ)고 보고, 차이는 추정 오차뿐이라고 가정한다. 가중치는 `w_i = 1 / v_i`(v_i = se_i²)다.
- **랜덤효과:** 회사마다 참값이 다르고(θ_i), 그 참값들이 평균 μ, 분산 τ²의 분포를 따른다고 본다. 관측된 차이 = 회사 간 진짜 차이(τ²) + 추정 오차(v_i)다. 회사마다 LLM의 반응이 진짜로 다를 수 있으므로 이 연구에 더 맞다.

**DerSimonian–Laird 추정(코드 `dl_weighted_mean`).**
```
1) 고정효과 평균:   μ_FE = Σ w_i y_i / Σ w_i,   w_i = 1 / v_i
2) 이질성 통계량:   Q = Σ w_i (y_i − μ_FE)²
3) 보정 상수:       C = Σ w_i − Σ w_i² / Σ w_i
4) 회사 간 분산:    τ² = max(0, (Q − (k − 1)) / C)
5) 랜덤효과 가중치: w_i* = 1 / (v_i + τ²)
6) 평균과 표준오차: μ = Σ w_i* y_i / Σ w_i*,   SE(μ) = √(1 / Σ w_i*)
```
- Q는 "추정 오차만으로 기대되는 것보다 회사 간 차이가 얼마나 큰가"를 잰다. 오차뿐이면 Q의 기댓값이 k − 1이다(k = 회사 수). 이를 넘는 만큼을 τ²로 본다(적률법).
- τ²가 크면 모든 회사의 가중치가 비슷해진다. 정밀한 회사 하나가 평균을 독점하지 못한다.

**I²(이질성 비율).**
```
I² = max(0, (Q − (k − 1)) / Q)
```
관측된 변동 중 진짜 회사 간 차이가 차지하는 비율이다. 0.25/0.5/0.75를 흔히 낮음/중간/높음으로 본다.
- 주식 수 2배: I² = 0. 모든 회사가 똑같이 반응한다.
- 현금배당: I² = 0.81. 평균 1.61이 "전형적인 회사"를 대표하지 못할 수 있다.

**CI 폭에서 표준오차 역산.**
```
SE ≈ (CI 상한 − CI 하한) / 3.92
```
정규분포에서 95% CI는 추정치 ± 1.96 × SE이므로 폭은 2 × 1.96 × SE = 3.92 × SE다. 부트스트랩 CI만 있고 SE가 없을 때 쓴 근사다. CI가 비대칭이면 부정확해진다(4절).

**한 회사의 여러 셀 합치기.** 회사 간 평균 R의 전체 분석에서는 한 회사의 여러 셀(2/5/10%, 규칙 크기)을 먼저 역분산 가중으로 합쳤다. 그다음 회사들을 랜덤효과로 합쳤다. 회사 간 독립성을 지키려는 단계다.

### 3.9 변형 크기 규칙의 유도

**목표.** 회사별 R의 표준오차가 s* 이하가 되도록 변형 크기 X를 정한다.

**유도.**
1. 기준 셀과 변형 셀에 각각 n번 반복하고, 반복 간 표준편차가 σ(주당 원)라고 하자. 두 셀 대표값 차이의 표준오차는 약 `σ × √(1/n + 1/n) = σ√(2/n)`이다. 평균 차이의 공식을 근사로 쓴 것이다.
2. `R = 차이 / ΔV*`이고 ΔV*는 고정값이므로 `SE(R) ≈ σ√(2/n) / |ΔV*|`다.
3. `SE(R) ≤ s*`가 되려면 `|ΔV*| ≥ σ√(2/n) / s*`여야 한다.
4. 현금·비영업자산 변형에서 `|ΔV*| = X / N`이므로 `X ≥ σ√(2/n) / s* × N`이다. 이것이 사전등록의 "정밀도 하한"이다.

**최종 규칙.**
```
X = min( max(정밀도 하한, 0.05 × 주주가치), 0.20 × 주주가치 )   (현금은 보유 현금 이하)
```
- 5% 하한(D3.5): 노이즈가 작은 회사에 너무 작은 변형이 주어지는 것을 막는다. 변형 크기가 회사 특성과 엮이는 것과 반올림 취급을 피하려는 장치다.
- 20% 상한(D7.7): 비현실적인 변형을 막는다.
- 하한이 상한을 넘으면 n을 5씩 늘려 40까지 시도하고, 그래도 넘으면 제외한다.

**변동계수 기준으로 바꾸면.** 상한 조건 `σ√(2/n)/s* ≤ cap × V`를 정리하면 다음과 같다.
```
CV = σ / V ≤ s* × cap / √(2/n)
```
- s* = 0.1, cap = 10%, n = 20: 0.01 / √0.1 = **3.2%**(최초 계획)
- s* = 0.2, cap = 20%, n = 20: 0.04 / √0.1 = **12.6%**(채택값)

실제 CV 중앙값이 26~103%였으므로 대부분의 회사가 통과하지 못했다(현금 8개사, 비영업자산 28개사). 그래서 G4가 실패했고, 대안(D7.8)으로 단계별 크기(장부 자본의 2/5/10%)를 전 기업에 실행했다.
- 단계별 크기는 **장부 자본(재무상태표의 자본총계)** 기준이다. 크기 규칙은 **모델이 낸 주주가치** 기준이다. 둘은 다르다.

### 3.10 반응비율 R의 통계적 성질

```
R = (중앙값(V_변형) − 중앙값(V_기준)) / ΔV*
```
- **비율 추정량의 불안정성.** 분자는 두 노이즈 섞인 중앙값의 차이다. 분모는 고정된 이론값이다. |ΔV*|가 노이즈 σ에 비해 작으면 R은 사실상 "노이즈 ÷ 작은 수"가 되어 ±수십까지 튄다. 2% 단계의 R 중앙값이 현금 −0.04, 비영업자산 0.87로 흩어진 이유다. 회사별 R의 CI 폭 중앙값이 현금 24, 비영업자산 18이었다.
- **부호 반전.** 기준 가치가 0 근처면 작은 흔들림에도 부호가 바뀐다. D7.5(기준 중앙값 ≤ 0 회사 제외)가 필요했던 이유다.
- **회사 간 평균의 힘.** 회사별로는 판정이 거의 불가능해도, 노이즈가 회사 간에 독립이면 평균의 표준오차는 약 1/√(회사 수)로 줄어든다. 사후 분석에서 120여 개사를 모아 평균 R을 추정할 수 있었던 근거다.
- **"중앙값의 차이" vs "차이의 중앙값".** R은 두 셀 중앙값의 차이를 쓴다. 실행끼리 짝이 없으므로(독립 호출) 이것이 자연스러운 정의다.

### 3.11 합성 에이전트 검증

실제 LLM에 돈을 쓰기 전에, **참값을 아는 가짜 에이전트**를 같은 파이프라인(변형 → 실행 → 파싱 → 지표)에 넣어 지표가 참값을 복원하는지 확인했다(P6). 이는 측정 도구 자체의 타당성 검증이다.

| 에이전트 | 설계된 행동 | 복원된 값 |
|---|---|---|
| Oracle(노이즈 5%) | 공시대로 정확히 평가 | β ≈ 1.00, R 0.96~1.02, ε = 0, E9 성공 100% |
| Anchored | 공시 무시, 고정값 | β = 0.000 |
| Mixture(w = 0.6) | 공시 60% + 앵커 40%(로그 가중) | β = 0.596 |
| 조건별 혼합 | 업종 0, 이름 0.2, 기억 0.3 | 0.000 / 0.203 / 0.299 |
| NoDilution | 희석 무시 | R_dil ≈ −0.04, E9 반영 실패 100% |
| CalcError | 자기 계산에서 10% 틀린 값 보고 | ε = 10.0%, E9 계산 실패 100% |

결론: 측정이 실패한다면 그것은 도구 문제가 아니라 실제 모델 행동(특히 노이즈) 때문이라는 근거가 된다.

### 3.12 판정 규칙: "지지", "지지되지 않음", "결론 유보"

사전등록한 판정 규칙:
- **지지(supported):** Holm 보정 p < 0.05이고 예측 방향
- **지지되지 않음(not supported):** 95% CI가 실질적 크기의 효과를 배제
  - H1, H3: CI 하한 > 0.9(의미 있는 둔화나 과소반영이 없음)
  - H2a: CI 상한 < 0.02
  - H2b: CI 상한 < 0
- **결론 유보(inconclusive):** 그 외. 효과가 있을 수도 없을 수도 있다.

**"증거의 부재는 부재의 증거가 아니다."** H2a, H2b, H3의 "결론 유보"는 "기억 효과가 없다"는 뜻이 아니다. **"노이즈 때문에 있는지 없는지 판단할 수 없다"**는 뜻이다. 반면 H1의 "지지되지 않음"은 "대형주의 실질적 둔화는 없다"는 적극적 결론이다. 동등성 논리(3.5의 TOST와 같은 발상)를 쓴 것이다.

## 4. 이 연구가 의존하고 전제하는 수리통계적 가정

각 가정마다 **무엇을 전제하는지**, **깨지면 무엇이 달라지는지**, **연구가 어떻게 대응했는지**를 정리했다.

### 4.1 측정의 전제

**(1) 이론 반응은 "가정 고정"을 전제한다.**
- 무엇을: 규모 ×k에 β = 1이 정답인 것은, 성장률·마진·WACC 같은 비율 가정이 규모와 무관하게 유지된다는 전제에서다. 현금 −X에 R = 1이 정답인 것도 EV가 그대로라는 전제에서다.
- 왜 문제가 되나: 현실의 애널리스트도 "회사가 2배 크면 위험이 낮다"며 WACC를 낮출 수 있다. 그러면 β ≠ 1이 비합리적이라고 단정할 수 없다. 이 연구의 β는 "합리성"이 아니라 **"공시 숫자 외의 요인이 끼어든 정도"**로 읽어야 한다.
- 구조 T의 의미: 비례 계산을 파이썬이 하므로 β = 0.993은 결국 "모델이 규모가 바뀌었다고 가정을 바꾸지는 않는다"는 뜻이다(결과 보고서 H1 해석).

**(2) 자기 기준(V₀, N)으로 이론값을 계산한다.**
- 무엇을: ΔV*는 모델이 기준 셀에서 낸 가치와 주식 수의 중앙값을 쓴다. 진짜 가치가 아니다.
- 함의: R = 1은 "진짜로 맞았다"가 아니라 **"자기 평가와 일관되게 반응했다"**다. 기준값 자체가 노이즈 있는 추정치이므로 분모에도 오차가 있다. 이 오차는 분석에서 무시됐다. 특히 CB에서는 E/N이 내가격 판정을 좌우한다.

**(3) 섭동은 의도한 정보만 바꾼다.**
- 무엇을: 현금배당은 현금만, 비영업자산은 자산·자본만 바꾼다고 가정한다.
- 실제: 배당은 DPS도 바꾼다(주주환원 신호). 변형된 숫자가 "이상해 보여서" 다른 판단을 부를 수도 있다. 다만 이상 경고는 변형 없는 입력에서도 56%로 높아 판별력이 없었다.

**(4) 분해의 해석은 "조건이 의도한 정보만 다르다"를 전제한다.**
- 항등식 `총 = 업종 + 이름 + 기억`은 대수적으로 항상 참이다. 하지만 각 항을 **원인별 효과**로 읽으려면 추가 전제가 필요하다.
  - 가짜 이름이 아무 연상도 일으키지 않는다(예: "하늘빛헬스케어"가 특정 이미지를 주지 않음).
  - 업종 라벨이 회사를 특정하지 않는다(D4.2로 대응).
  - 숫자만으로 회사를 알아보지 않는다(E5로 측정: 대형주 A 3%).
- 또 네 β의 차이이므로 각 β의 추정 오차가 합쳐져 분해 성분의 CI가 넓어진다(모든 CI가 0 포함).

### 4.2 표본추출과 독립성의 전제

**(5) 반복 실행은 독립 동일 분포(i.i.d.) 표본이다.**
- 무엇을: 같은 프롬프트의 반복은 같은 분포에서 독립적으로 뽑은 표본이라고 본다. 부트스트랩, HC3, 크기 규칙이 모두 이 전제에 기댄다.
- 근거: 각 호출은 상태가 없는 별개 요청이고 온도 0.3 샘플링이다. 반복 번호가 캐시 키에 들어가 같은 응답을 재사용하지 않는다.
- 위험: 제공자가 실행 중 모델을 바꾸면 분포가 달라진다. 모든 호출의 `model_reported`를 기록했고, 바뀌면 실행을 멈추게 했다. 실제로 한 버전만 쓰였다. 서버 측 캐싱이나 배치 효과는 통제할 수 없다.

**(6) 회사들은 서로 독립이다.**
- 메타분석, Wilcoxon, 회귀가 모두 회사를 독립 관측치로 본다.
- 같은 그룹 계열사(예: 삼성 계열 여러 개)는 모델의 기억이 상관될 수 있다. 업종 FE가 일부만 흡수한다.

**(7) 표본은 모집단을 대표한다.**
- 표본은 무작위가 아니라 **목적 표집**이다(시가총액 상위 50, 뉴스 노출로 층화한 중형 50, 희석 잠재력 상위 소형 50).
- 따라서 결과를 "한국 상장사 전체"로 일반화하는 데는 한계가 있다. 비교 대상 집단 간 대조(대형 vs 소형)가 주목적이다.

### 4.3 분포와 근사의 전제

**(8) 로그 변환과 비양수 제외의 선택 편향.**
- log V는 V > 0에서만 정의된다. 0 이하 실행과 기준 중앙값 ≤ 0 회사를 빼면, **남은 표본은 "모델이 양수로 평가한 경우"로 선택된 표본**이다.
- 예: k가 작을 때 음수가 더 자주 나오면, 낮은 k에서 양수인 실행만 남아 평균이 위로 치우친다. 그러면 β가 작게 추정되는 쪽으로 편향될 수 있다(절단 편향, truncation bias).
- 대응: 제외 개수를 보고했고, 중앙값 기반 β(R9)로 확인했다. 소형주에서 이 문제가 가장 크다.

**(9) 정규 근사로 SE를 역산한다.**
- `SE = CI 폭 / 3.92`는 추정량이 대칭 정규분포라는 전제다. 부트스트랩 백분위수 CI는 비대칭일 수 있다(예: [−0.55, +10]).
- 깨지면 가중치가 틀어지고, 메타분석 평균과 CI가 왜곡된다. 보고서도 이를 한계로 적고 비가중 중앙값을 함께 제시했다.

**(10) 랜덤효과 모형의 분포 가정과 소수 표본 문제.**
- DL은 회사 참값이 정규분포를 따르고 회사 내 SE를 정확히 안다고 가정한다(실제로는 추정치).
- 회사 수가 적으면(H3: 15개) τ² 추정이 매우 부정확하다. DL CI는 τ²의 불확실성을 무시해 **너무 좁아지는** 경향이 있다. 대안은 Hartung–Knapp–Sidik–Jonkman 보정이나 REML이다(이 연구에서는 쓰지 않음).
- 사전등록 계획(P10 §9)은 이 위험에 대비해 비가중 평균과 Wilcoxon을 함께 보고하게 했다. H3에서는 비가중 평균 −3.46, Wilcoxon 중앙값 −1.01, DL 0.744로 방법마다 크게 달랐다. 이것이 "희석 반응의 부호 자체가 불안정하다"는 해석의 근거다.

**(11) 크기 규칙은 평균 차이 공식을 근사로 쓴다.**
- σ√(2/n)은 **평균** 차이의 표준오차다. 정규분포에서 **중앙값**의 표준오차는 평균의 약 1.25배(√(π/2))다. 따라서 정규 노이즈라면 실제 SE(R)는 설계값 s*보다 약 25% 크다.
- 반대로 꼬리가 두꺼운 노이즈(실제 LLM 출력)에서는 중앙값이 평균보다 효율적이다. 근사의 방향은 노이즈 분포에 달려 있다.
- σ 자체도 E0의 10~30회 반복으로 추정한 값이다. 파일럿에서 5회만 쓰면 σ 추정이 0.2~1.9배로 흔들렸다.

**(12) 부트스트랩은 셀 안 표본 크기가 충분하다고 전제한다.**
- 셀당 10회 반복은 작다. 작은 표본의 중앙값 부트스트랩은 분포가 이산적이고 CI 포함률이 명목값(95%)에 못 미칠 수 있다.
- 합성 검증의 포함률 96.5%는 **로그정규 5% 노이즈**라는 이상적 조건의 결과다. 실제 노이즈(CV 26~103%, 부호 반전, 극단값)에서의 포함률은 검증되지 않았다.

**(13) Wilcoxon 검정의 대칭성 전제.** 부호순위 검정이 "중앙값 = 0" 검정이 되려면 차이의 분포가 대칭이어야 한다. E_i 분포가 비대칭이면 결과는 위치 이동 전반에 대한 검정으로 읽어야 한다.

### 4.4 회귀 모형의 전제

**(14) 기억 강도 M_i의 측정 오차는 계수를 0 쪽으로 줄인다(errors-in-variables).**
- M_i는 6문항 × 3회의 퀴즈 점수로, 진짜 "기억"의 노이즈 섞인 대리변수다. Q5 채점 방식에 따라 γ₁이 0.10~0.44로 바뀌었다.
- 고전적 측정 오차가 있으면 OLS 계수는 `γ × Var(M) / (Var(M) + Var(오차))`로 **0 쪽으로 감쇠(attenuation bias)**한다.
- 따라서 H2b의 "결론 유보"는 기억과 둔화의 관계가 진짜로 약해서일 수도 있고, M_i 측정이 거칠어서일 수도 있다. 두 가능성을 이 설계만으로는 구분하지 못한다.

**(15) 종속변수 E_i 자체도 추정치다.**
- E_i = β_D − β_C는 각각 표준오차가 있는 두 추정치의 차이다. 이를 WLS 가중치(1/se²)로 처리했지만, 오차가 큰 종속변수는 R²를 낮추고 검정력을 떨어뜨린다.

**(16) E7 회귀의 누락변수 가능성.**
- b₂ > 0을 "기억한 옛 주가가 끌어당긴다"로 읽으려면, log V_A가 펀더멘털을 충분히 통제해야 한다.
- 만약 V_A에 담기지 않은 펀더멘털(예: 시장이 아는 성장성)이 P_old와 V_C 양쪽에 함께 관련되면, b₂는 기억이 아니라 그 펀더멘털을 잡은 것일 수 있다. 탐색적 결과로 분류된 이유 중 하나다.
- P_old 측정 시점은 학습 기준일(2025년 1월)이다. 실제 모델이 기억하는 가격이 정확히 그 시점이라는 보장은 없다.

**(17) 이분산 강건 표준오차도 독립성은 전제한다.** HC3은 분산이 달라도 되지만, 관측치끼리의 상관은 다루지 않는다. 그래서 여러 회사의 실행을 함께 쓰는 H1b에서는 회사 군집 표준오차를 썼다.

### 4.5 추론 절차의 전제

**(18) 다중비교 통제는 주 가설에만 적용된다.** Holm은 4개 주 가설의 FWER만 지킨다. 탐색적·사후 결과의 p값에는 다중성이 반영되지 않았다(3.6).

**(19) 사후 분석은 확증력이 없다.** 회사 간 평균 R과 경로 분해는 주 결과를 본 뒤 추가했다. 같은 데이터에서 가설을 만들고 검정했으므로, 독립 데이터로 재현하기 전까지는 탐색적이다.

**(20) 검정력이 결론의 성격을 정한다.** 노이즈(CV)와 표본 크기(H3는 15개)가 정한 검정력이 낮다. 그래서 "결론 유보"가 많은 것은 설계상 예견된 결과다(사전등록 §10에도 "소형주 검정력 가정이 낙관적"이라고 적었다).

### 4.6 외적 타당성의 전제

**(21) 특정 조건의 결과다.**
- 주 모델 하나(gemini-2.5-flash-lite), 구조 T, 한국어 프롬프트, 특정 입력 형식(주석은 BS에서 만든 요약, CB 문구는 구조화 데이터로 생성)이다.
- 비교 모델은 β_C 중앙값 0.979로 비슷했다. 그러나 학습 기준일이 달라 같은 질문에 대한 재현으로 보기는 어렵다.

**(22) 연구자가 고정한 가정이 결과에 들어 있다.**
- D&A = capex(준수율 68%), 연말 할인, 브리지 정의는 측정의 틀을 정한다.
- 이 규칙들이 노이즈 수준과 측정 가능한 회사 수를 바꿨다(파일럿 2→3라운드에서 CV 감소).

| H3 R_dil = 0.744 [−0.14, 1.63], n = 15 | 내가격 조건(1.5) 때문에 표본이 15개로 줄어 검정력이 낮다(3.4). 방법마다 추정치가 크게 달라(4.3-10) 부호 자체가 불안정하다 |
| Holm 보정 p 모두 1.000 | 원래 p값이 모두 0.28 이상이라 보정 후 1로 잘렸다(3.6) |
| H2c b₂ = 0.245, p = 0.003 | 낡은 앵커(1.6). 탐색적이고 누락변수 가능성(4.4-16)이 있지만, 20여 개 탐색 검정 중에서도 p가 작은 편이다 |
| P·R 구조 계산 실패 98%, ε 중앙값 76% | 자기 일관성 지표(2.5). 모델에게 할인 계산을 맡기면 거의 항상 자기 가정과 맞지 않는 값을 낸다. 계산 위임이 전제 조건이다 |
| 주식 수 2배 평균 R = 1.007, I² = 0 | 주당 나눗셈만 바뀌는 변형이라 가정 노이즈가 상쇄된다. 이질성이 없다(3.8) |
| 현금배당 평균 R = 1.61, I² = 0.81 | 평균은 과잉 반응이지만 이질성이 매우 크다. 크기 규칙을 통과한 정밀한 8개사는 1.07이다. 배당 신호 효과(1.3) 가능성이 있다 |
| 경로 분해: Δ순차입금/X = 1.00, ΔEV/X의 IQR ≈ [−4.5, 5.0] | 브리지 경로는 정확하다(1.2-5). 하지만 EV 경로의 가정 노이즈(1.2-6의 WACC 민감도)가 변형 효과보다 4배 넘게 크다. R의 부정확성은 "읽지 못해서"가 아니라 "매번 가정이 달라서"다 |
| 크기 규칙 통과: 현금 8개사, 비영업자산 28개사 | CV 기준 12.6%(3.9)에 비해 실제 CV 중앙값이 26~103%였다 |

**한 문장 요약.** 이 연구의 측정 도구(메타모픽 관계 + 자기 기준 이론값 + 부트스트랩 + 랜덤효과 평균)는 합성 검증에서 정확히 작동했다. 실제 LLM에서 회사별 판정이 어려웠던 이유는 도구가 아니라 **모델의 예측 가정이 실행마다 크게 흔들리는 노이즈** 때문이다. 이 노이즈 아래에서도 브리지 항목의 반영은 정확했고, 회사들을 평균하면 대체로 이론 크기만큼 반응했다.
